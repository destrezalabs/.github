# Destreza Labs

**Apps de test para preparar oposiciones.**

Destreza Labs crea aplicaciones de práctica para oposiciones: preguntas ligadas al artículo
del BOE que las respalda, repaso espaciado y un simulacro semanal con percentil. Un mismo
motor, una marca por cada colectivo.
